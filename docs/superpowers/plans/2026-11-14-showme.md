# ShowMe Implementation Plan（开发流程 + 分工）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 黑客松简化：每人用自己的 Claude 按顺序做自己的任务即可（「Native」方式）。只给纯逻辑函数写测试；界面类任务用「手动验证」步骤代替测试。

**Goal:** 一个 Mac 桌面工具：用户说出「软件 + 目标」，Gemini 看屏幕，在屏幕上框亮下一步要点的元素，逐步引导直到完成，并用 ElevenLabs 读出每一步。

**Architecture:** `client/`（Python + PyQt6，B 负责）负责截屏、透明高亮层、浮动面板、检测画面变化、播放语音；`backend/`（FastAPI，A 负责）负责调用 Gemini 决定下一步、ElevenLabs 合成语音、（加分）搜索官方文档。两边只通过 `docs/API.md` 里的 HTTP 接口通信。

**Tech Stack:** Python 3.12 + uv；后端 FastAPI、google-genai、Pillow、httpx；客户端 PyQt6、PyObjC（Cocoa / Quartz / Vision）、mss、numpy、Pillow、httpx；测试 pytest。

**Spec:** `docs/superpowers/specs/2026-11-14-showme-design.md`（接口细节以 `docs/API.md` 为准）

## Review Focus
1. **Retina / 缩放屏**：截图像素是逻辑尺寸的 2 倍，框必须按逻辑尺寸换算，否则框偏到右下 → C1 测试 `test_box_to_rect_uses_logical_size`
2. **Gemini 返回坏框**（ymin > ymax、超出 0–1000、只有 3 个数、`next` 却没框）→ 后端要修正或降级为 `unsure`，不能把坏数据传给客户端 → A1 测试 `test_normalize_box_*`、`test_next_without_box_becomes_unsure`
3. **后端没开 / 断网 / 超时**：客户端面板显示「连不上后端」之类的提示，不崩溃、可以重试 → C4 测试 `test_connection_error_is_friendly`
4. **高亮层自己被当成画面变化**：等待用户操作时，检测画面变化的截图里有高亮层；基准帧必须在高亮层显示之后取 → C5 测试 `test_static_overlay_is_not_change`，C6 手动验证
5. **鼠标光标闪烁、时钟跳秒这类小变化**：不能误判成「用户完成了这一步」→ C5 测试 `test_small_noise_ignored`

### Task A1: `/api/next-step` 数据结构 + mock（19:00 前合进 main，B 要用）

**Interfaces:**
- Produces（`backend/app/steps.py`）：
  - `class HistoryItem(BaseModel)`: `instruction: str`, `ok: bool | None = None`
  - `class NextStepIn(BaseModel)`: `app: str`, `goal: str`, `lang: Literal["zh", "en"] = "zh"`, `screenshot: str`, `history: list[HistoryItem] = []`, `expect: str | None = None`, `guide: list[str] | None = None`
