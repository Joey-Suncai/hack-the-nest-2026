## 启动工作流
1. **两人一起填完本文件**，提交：`git commit -m "docs: fill IDEA.md"`
2. **让 Claude 更新文档**，对 Claude 说：
   > 读 docs/IDEA.md，更新 CLAUDE.md 的「项目」部分，并按 MVP 功能起草 docs/API.md 的接口（请求/返回都给例子 JSON）
3. **两人过一遍 API.md**（10 分钟），定下来后提交。
4. **并行开工：**
   - B（前端）：按 API.md 的例子在 `frontend/src/mocks/` 写假数据，`frontend/.env.local` 设 `VITE_USE_MOCKS=1`，不用等后端
   - A（后端）：在 `backend/app/main.py` 实现接口，prompt 写在 `backend/prompts/`；没 key / 省额度时用 `make mock`
5. **每 1–2 小时合并进 main 一次**（流程见 docs/02_团队协作工作流.md），合之前本地 `make dev` 能跑通。
