# 项目点子：ShowMe（名字暂定）

> 完整设计：`docs/superpowers/specs/2026-11-14-showme-design.md`
> 开发流程 + 分工：`docs/superpowers/plans/2026-11-14-showme.md`

## 1. 一句话产品定义
- **给谁用：** 第一次用某个 Mac 软件的人（学生、转行的人、长辈）
- **解决什么痛点：** 不知道下一步该点哪里；截图问 AI、看教程、视频通话让人一步步教都很慢
- **用了什么 AI 能力：** Gemini 看屏幕截图 + 空间定位（框出按钮位置）+ 判断上一步是否完成；ElevenLabs 读出每一步
- 一句话：「说出你想做什么，ShowMe 看着你的屏幕，直接把下一步要点的按钮框亮。」

## 2. 目标赛道
- AI/ML、Best use of ElevenLabs、Computer Science Department
- Devpost 上另外勾选：MLH Best Use of Gemini API

## 3. MVP 功能（按优先级）
1. 说出目标：浮动面板输入「软件 + 想做什么」
2. 高亮下一步、逐步推进：截屏 → Gemini 返回说明 + 元素框 → 屏幕上画发光框 → 检测到屏幕变化后确认 → 下一步，直到完成
3. 语音讲解：每一步用 ElevenLabs 读出来（中 / 英）

加分项：任务开始前先用 Google 搜索读官方帮助文档，生成步骤大纲

## 4. Demo 脚本（2 分钟）
1. 「我从来没用过 Numbers，想把这份数据做成柱状图。」在面板里输入目标，点开始
2. 屏幕上「插入图表」按钮亮起，耳边听到「先点上方工具栏的『图表』」
3. 点完 → 框自动跳到「二维柱状图」→ 再点 → 「完成！」（这是「哇」的瞬间）
4. 换一个软件（系统设置 / Figma）再来一次，证明「任何软件都能用」
5. 收尾：「教你做，不替你做。任何软件，第一次用就像有人在旁边指给你看。」

## 5. 非目标（这次明确不做）
- 不替用户点击；不做手机端、Windows、多显示器
- 不做登录 / 账号；不部署（本地跑 demo）
- 不在后台一直监控，只在任务进行中截图
